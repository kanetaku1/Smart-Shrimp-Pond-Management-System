# ADR-001: 水位を唯一のPID制御対象とする

**Status:** `DECIDED`
**日付:** 2026-09-09

## Context
5つのセンサー（pH / 温度 / TDS / 濁度 / 水位）のうち、何をPIDの制御対象とするかを決めないと、
PID設計・Agentの行動空間・デモシナリオが確定しない。

## Options
- A: 水質パラメータ（pH / TDS / 濁度）をPIDで制御する
- B: 水位のみをPIDで制御し、水質は判断材料とする
- C: 温度も含めて制御する

## Decision
**B を採用。水位を唯一のPID制御対象とする。**

| 項目 | 値 |
|---|---|
| PID Input | 水位 [cm]（超音波センサー） |
| PID Setpoint | 目標水位 [cm] |
| PID Output | ポンプduty [-100〜+100%]（正＝給水 / 負＝排水） |
| 操作変数 | 給排水ポンプ |

## Reason
利用可能なアクチュエータが給排水ポンプであるため、ポンプ出力に対して直接的・単調・高速に応答するのは水位のみ。

- pH / TDS / 濁度：水交換を介した間接的な影響で、応答は時間オーダー。連続制御であるPIDの対象として適切でない
- 温度：外気温と日射が支配的で、給排水では実質的に動かせない
- 水位：分オーダーで応答し、単調性があり、PIDの適用対象として妥当

水質パラメータは制御対象ではなく、**Agentが水交換率を判断するための入力**として位置づける。

```text
Agent : 水交換率を決める（pH / TDS / 濁度を見る）  … 遅い・意味的判断
  ↓ setpoint
PID   : 水交換中も水位を保つ                      … 速い・物理的保証
  ↓ duty
Pump  : 給水 / 排水
```

給排水ポンプを同時運転すれば「水位を保ったまま水交換」が可能であり、
Agent＝何をするか / PID＝それを安全に成立させる、という責任分離（設計書 §37）が自然に成立する。

## Consequences
- 温度は制御対象外。**観測・可視化のみ**として提案書に明記する
- Agentの行動空間は「水位setpoint」と「水交換率」の2つに限定される
- Safety Layerが持つべきhard limitは、水位の上下限・最大連続運転時間・最小停止時間

## Open Questions
- ポンプがON/OFF駆動か流量可変か（→ ADR-002 で扱うPID出力方式に影響）
