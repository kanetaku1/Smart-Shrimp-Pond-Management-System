# 用語定義

| 用語                             | 定義                                                                                                                                                               |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| DO                               | 溶存酸素。エビの生存に直結する水質指標                                                                                                                             |
| pH / TDS / 濁度 / 水位           | 水質モニタリング項目                                                                                                                                               |
| 閾値超過アラート                 | あらかじめ設定した基準値を各水質項目が超えた場合に発報される通知                                                                                                   |
| AI予測アドバイス                 | 現場のIoTデータ・数値変化の履歴をAIが学習し、今後の傾向予測や対応の提案をTechnical Managerに提示する機能                                                           |
| 日次報告書                       | Technical Managerが1日1回、池ごとの状態（生存数・死亡数・天候等）を入力する報告フォーム                                                                            |
| 週次サンプリング                 | 週1回程度、エビを採取して重量・尾数を測定し、成長・生存状況を把握する現場作業およびその入力データ                                                                  |
| ABW／ADG／SR／Biomass／FCR／COGS | 週次サンプリング等をもとに算出する養殖KPI（平均体重／日間成長速度／推定生存率／推定生体量／飼料要求率／1kgあたり生産原価）。算出式は業務ルール確定後に別途定義する |
| 健康スコア・危険度               | 生物学的リスク分析により算出される、池の状態を表すスコア（0〜100）およびステータス（正常・注意・警告）                                                             |
| 収穫推奨日                       | 収益最適化分析により算出される、予測利益が最大となる水揚げ候補日                                                                                                   |
| アクチュエーター                 | ポンプ・エアレーター等、池の環境を物理的に制御する機器                                                                                                             |
| PID制御                          | 目標値（閾値内の水質等）に対する自動制御アルゴリズム                                                                                                               |
| Safety Layer                     | 自動制御が誤作動した場合にも安全を確保するための制御層                                                                                                             |
| Human Override                   | 自動制御に対してTechnical Managerが手動で介入・上書きする操作                                                                                                      |
