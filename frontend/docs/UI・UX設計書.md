# UI/UX設計書

## 1 画面要件（一覧レベル）

| 画面ID | 画面名   | 概要  | 主な利用者  |
| ------ | ------------------------------------ | ----------------------------------------------------------------------------- | --------------------------------- |
| S-01   | ログイン画面   |   | 全ユーザー  |
| S-02   | 全社統合ダッシュボード（トップ画面） | 全ファームの状態サマリー、収益・リスク・将来在庫の3領域サマリー、アラート一覧 | Farms Manager   |
| S-03   | 収益シミュレーション画面   | 池別の収穫推奨日・利益予測・複数時点比較  | Farms Manager |
| S-04   | リスク・アラート画面   | 池別の健康スコア・危険度・要因・推奨アクション  | Farms Manager     |
| S-05   | 将来在庫カレンダー画面   | 週・サイズ別の出荷可能量予測  | Farms Manager     |
| S-06   | 池別詳細画面（ドリルダウン）   | 分析結果の根拠となる元データ・KPIの確認   | Farms Manager     |
| S-07   | 自ファーム池別モニタリング画面   | 池ごとのIoT詳細数値のリアルタイム表示   | Technical Manager   |
| S-08   | アラート確認画面   | 閾値超過時のアラート内容・詳細数値の確認  | Technical Manager   |
| S-09   | 閾値設定画面   | 水質項目ごとの閾値設定  | システム管理者／Technical Manager |
| S-10   | AI予測アドバイス画面   | IoTデータの傾向予測・対応アドバイスの表示   | Technical Manager   |
| S-11   | 日次報告書入力画面   | 池ごとの日次報告（生存数・死亡数・天候等）の入力  | Technical Manager   |
| S-12   | 週次報告書入力画面   | 池ごとのサンプリング結果の入力  | Technical Manager   |
| S-13   | 日次・週次報告履歴画面   | 過去の日次・週次報告の閲覧・検索  | Technical Manager   |
| S-14   | 自動制御監視・承認画面   | アクチュエーターの動作状況確認、自動制御の承認、Human Override操作  | Technical Manager   |
| S-15   | ユーザー・権限管理画面（RBAC）   |   | システム管理者  |
