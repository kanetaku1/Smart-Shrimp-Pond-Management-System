# Glossary

| Term | Definition |
| --- | --- |
| DO | Dissolved oxygen. A water-quality indicator directly related to shrimp survival |
| pH / TDS / Turbidity / Water Level | Water-quality monitoring items |
| Threshold-exceedance Alert | A notification issued when a water-quality item exceeds a predefined reference value |
| AI Prediction Advice | A function in which AI learns from field IoT data and historical numerical changes, then presents forecasts of future trends and response suggestions to the Technical Manager |
| Daily Report | A reporting form in which the Technical Manager enters the condition of each Pond once per day, including surviving population, deaths, weather, etc. |
| Weekly Sampling | Field work performed approximately once a week in which shrimp are sampled and their weight and number are measured to understand growth and survival, together with the resulting input data |
| ABW / ADG / SR / Biomass / FCR / COGS | Aquaculture KPIs calculated from weekly sampling and other data (average body weight / average daily growth / estimated survival rate / estimated biomass / feed conversion ratio / production cost per kg). Calculation formulas will be separately defined after business rules are finalized |
| Health Score / Risk Level | A score (0–100) and status (Normal / Attention / Warning) representing Pond condition as calculated through biological risk analysis |
| Recommended Harvest Date | A candidate harvest date calculated through revenue optimization analysis at which predicted profit is maximized |
| Actuator | Equipment such as pumps and aerators that physically control the Pond environment |
| PID Control | An automatic control algorithm for maintaining target values such as water-quality conditions within thresholds |
| Safety Layer | A control layer designed to ensure safety even if automatic control malfunctions |
| Human Override | An operation in which the Technical Manager manually intervenes in and overrides automatic control |
| Actual Value | A value that has actually been measured, entered, or confirmed. It must be clearly distinguished from forecast and estimated values on the screen |
| Forecast Value | A value calculated by a model or rule representing a future condition or quantity. The target period and the fact that it is a forecast must be displayed on the screen |
| Estimated Value | A value calculated from existing data for a condition that cannot be directly observed. The calculation method or basis should be available for confirmation |
| Aggregated KPI | A management or production indicator for the Farms Manager calculated by aggregating multiple sensor values, input values, or period data |
| Alert Status | The processing status of an Alert. The statuses are Unacknowledged, Acknowledged, In Progress, and Resolved |
| AI Recommendation | A forecast or response proposal presented by AI based on data. AI does not directly operate Actuators; execution occurs after human judgment |
